# vehicleManagementInsurance
A full-stack auto service management web app built with Node.js, Express, MongoDB, and Vanilla JS.
AutoServe is a vehicle service management platform that allows customers to book 
auto services, track their service status, and manage billing. Service providers 
can manage assigned jobs, while admins have full control over users, bookings, 
and services.

Tech Stack:
- Frontend: HTML, CSS, JavaScript, Tailwind CSS, Vite
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT
